# Sharing review — 2026-10-08

## User authorization and release boundary

The corresponding project owner explicitly authorized publishing shareable, study-generated statistical records after a permission check. This release is limited to the authors' numerical study summaries, anonymous cluster sums and counts, and their reconstruction scripts. No source dataset material or third-party implementation is copied into this audit bundle.

## Primary sources inspected

- MMSA repository and MIT software license: https://github.com/thuiar/MMSA and https://github.com/thuiar/MMSA/blob/master/LICENSE . Its README provides dataset access links and identifies feature packages. The software license is not treated as a blanket license to redistribute the linked data.
- CMU Multimodal SDK software license: https://github.com/CMU-MultiComp-Lab/CMU-MultimodalSDK/blob/main/LICENSE . The additional notice at https://github.com/CMU-MultiComp-Lab/CMU-MultimodalSDK/blob/main/LICENSE.txt explicitly leaves dataset usage, copyright and subject rights with users.

Accordingly, no permission to redistribute raw MOSI/MOSEI media, transcripts, dataset features or labels is asserted. Readers must obtain such assets through the providers under their terms. The numerical export consists of model-evaluation quantities generated by this study and omits direct source identifiers and mappings. The authors' authorization covers publication of these research outputs; no new license over upstream data or code is implied. This is a documented, scope-limited publication check, not a legal opinion or formal anonymization guarantee.

## Included and excluded fields

Included: dataset and model-condition names, sample counts, metrics, contrast sums, cluster counts, reproducibility seeds, anonymous within-family group ordinals, hashes, formulas and source citations.

Excluded: raw text, token IDs, audio, images, embeddings, ground-truth labels, individual predictions, selected positions, original clip/video/speaker IDs, identifier lookup tables, local absolute paths, server addresses, credentials and checkpoints.

Cluster sufficient statistics retain the original statistical grouping. Some MOSEI clusters contain one segment, so their sum is a segment-level contrast; identities, input content and outputs are still excluded. These files support arithmetic auditing rather than reconstruction of source content.
